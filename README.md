# Pandoracube · Team Vent 스터디 인증

Pandoracube와 Team Vent가 발급하는 스터디 수료 인증 페이지 모음입니다. 각 페이지에서 수료자 이름, 스터디명, 발급번호, 발급일을 확인할 수 있습니다.

## 인증 스터디

- [25-26 실시간 멀티플레이 스터디](./verify/realtime-multiplay-2026-01/info.md)

## 소유권

프로젝트는 2026년 Team Vent 내에서 개발되었습니다. 수료 데이터와 이미지의 저작권은 세종대학교 판도라큐브 게임제작 동아리와 세종대학교 창업동아리 벤트에 있습니다.

## 운영 문서

인증 데이터 작성, 페이지 생성 및 Cloudflare Pages 배포 방법은 [운영 문서](./docs/operations.md)를 참고하세요.
